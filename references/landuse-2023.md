# 《国土空间调查、规划、用途管制用地用海分类指南》（2023）参考表

## 使用说明

- 本文件供技能做用地归类与平衡表汇总时参考，配套机器可读配置为 `assets/classification.2023.json`。
- 本表为**常用类目摘编**，代码与名称以自然资源部发布的官方原文为准。遇到表中未收录的类目，先查原文，再按 `classification.2023.json` 的相同结构补充，**不得凭推测填码**。
- 统计口径提示：本指南覆盖全域全要素（含耕地、林地、陆地水域等非建设用地），做"城市建设用地平衡表"时需与委托方确认是否只统计建设用地范围内的类目。
- 新增类目：`0809 15分钟社区生活圈综合公共服务设施用地`（08 下二级类）、`0909 商业服务业混合用地`（09 下二级类）为项目新增二级类，已同步进 `classification.2023.json` 与图层映射，可直接用于归类与平衡表汇总。

## 平衡表汇总口径

1. **一级类汇总**：按两位代码聚合，适合做用地结构分析（居住、公服、商业、工矿、交通、公用、绿地占比）。
2. **二级类展开**：按四位代码展开，适合报审附表；一级类行取其下二级类之和。
3. **建设用地口径**：如需"城市建设用地"总量，通常由 07、08、09、10、11、12、13、14、15 等建设用地类目构成，**具体取舍必须向委托方确认**，脚本不做隐式裁剪，仅提供 `--include-codes` / `--exclude-codes` 过滤器。
4. **人均用地**：`面积 / 人口规模`，仅当传入 `--population` 时计算；人口口径（常住人口/规划人口）需在报告中注明。
